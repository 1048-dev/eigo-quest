# エマ先生の 授業台本 設計（run8）

すべての レッスン（1,200）に、エマ先生が 3〜4 分で 教える「授業の 台本」を つける。
台本は ① いまの アプリの バーチャル先生プレイヤー（アニメの エマ先生 ＋ 黒板 ＋ 字幕 ＋ ブラウザの 音声）で 再生し、
② あとで AI アバター動画サービスに わたして 本物の 動画に できる（scripts/teacher-export.ts → videoUrl）。

- データ: `LessonDef.teacher?: TeacherScript`（src/lib/domain/types.ts）。省略可（後方互換）。
- むかしの `teacherScript`（約 80 字の みじかい あいさつ）は そのまま のこす（要約・互換用）。
- 置き場所: content/curriculum/worlds/world-NN.json の 各レッスン。ブラウザに カリキュラム全体は 送らない（1 レッスンずつ API で 返す。contracts.ts の `TeacherScriptSchema` は こわれた セグメントを すてる）。
- 長さの 計算: src/lib/teacher/timing.ts（テスト・プレイヤー・エクスポーターで 共通）。
- 下書きの とりこみ: `npx tsx scripts/teacher-merge.ts tmp-teacher/xxx.json`（すでに teacher が ある レッスンは とばす。やりなおしても 安全。`--dry` で チェックだけ）。

## 1. 台本の 形

```ts
teacher: {
  minutes: 3.5,               // 予定の 長さ（3〜4）
  segments: [{
    kind: "greet"|"goal"|"words"|"expressions"|"phonics"|"tpr"|"repeat"|"check"|"wrap",
    lang: "en"|"ja"|"mix",    // say の 言語。mix は 日本語と 英語が まざる（プレイヤーが 文ごとに 声を きりかえる）
    say: string,              // エマ先生が 話す ことば（TTS / アバター動画の テキスト）
    subtitleJa?: string,      // 日本語字幕（ルールとして すべての セグメントに つける）
    subtitleEn?: string,      // 英語字幕（英語が 入る セグメントに つける。mix では 英語の 部分）
    slide?: { title, items[], emoji? },  // 黒板
    gesture?: "wave"|"point"|"nod"|"clap"|"think"|"open_hands"|"mime",
    pauseMs?: number          // 話した あとの まち時間（子どもが まねして いう・からだを うごかす）
  }]
}
```

## 2. 授業の ながれ（インプット → アウトプット）

かならず この 順番。1 つの kind を 何セグメントに わけても よい（ふつう 16〜22 セグメント）。

| # | kind | なにを する | めやす |
|---|------|-------------|--------|
| 1 | greet | あいさつ・前回とのつながり・きょうの 場面へ さそう | 10〜15 秒 |
| 2 | goal | きょうの ゴール（できるように なること 1〜2 個）。黒板に 文型 | 10〜15 秒 |
| 3 | words | 新しい ことば。1 語ずつ「お手本 → いみ → ジェスチャー → まねして」 | 30〜45 秒 |
| 4 | expressions | 会話の 小さな 場面（Haru・Riko などの セリフ）で 表現を 見せる → 使いかたの ポイント | 25〜35 秒 |
| 5 | phonics | きょうの 音・つづり。口の 形の コツ → 例の ことば → まねして | 20〜30 秒 |
| 6 | tpr | 「からだで やってみよう」。動きの 説明 → 先生の 合図 → 子どもが 動く（スピード チャレンジ も） | 25〜35 秒 |
| 7 | repeat | 「まねして いってね」。1 セグメント 1 フレーズ ＋ pauseMs。さいごに じぶんの ことに かえて いう | 20〜30 秒 |
| 8 | check | クイズ 1 問（2 択など）→ 考える 間（pauseMs）→ こたえ と ほめる | 10〜15 秒 |
| 9 | wrap | まとめ（できたこと 2〜3 個）・ほめる・次の 会話ステップへ・See you! | 10〜15 秒 |

インプット（1〜5）で たくさん 聞かせてから、アウトプット（6〜8）で からだと 口を 使う。

## 3. 長さ（3〜4 分）

`scriptMs()` = すべての セグメントの（話す 時間 ＋ pauseMs ＋ 0.5 秒）。

- 英語: 1 語 0.46 秒（こども向けに ゆっくり、約 130 語/分）
- 日本語: 1 文字 0.145 秒（ひらがな多め、約 7 文字/秒。スペース・記号は 数えない）
- 合計が 180〜240 秒（3〜4 分）。めやすは 190〜225 秒。`minutes` は 3〜4 の 数（0.5 きざみで 近い 値）。

## 4. 英語の わりあい（イマージョン）

`englishShare()` = 話す 時間の うち 英語の わりあい（まち時間は のぞく）。`immersionFor(world)` で チェック。

| ワールド | ステージ | 話しかた | 英語の わりあい | ja だけの セグメント |
|----------|----------|----------|-----------------|---------------------|
| 1〜2 | 1 | 日本語で 説明、英語は お手本・合図・まねする 文 | 15〜50% | 可 |
| 3〜6 | 1 | 英語と 日本語 半分ずつ（英語 → すぐ 日本語で たすけ） | 40〜70% | 可 |
| 7〜12 | 1 | やさしい 英語が 中心、日本語は みじかい たすけ（「＝ ～ だよ」） | 65〜92% | 不可（mix か en） |
| 13〜20 | 2 | 英語。日本語は ほんの 少しの ヒント（ことばの いみ 1〜2 語） | 88〜100% | 不可 |
| 21〜40 | 3〜5 | 英語だけ（日本語は 字幕で） | 99.5〜100% | 不可（すべて en） |

- 字幕は どの ワールドでも 日本語を かならず つける（英語だけの 回でも subtitleJa あり）。
- 日本語は ひらがな多め・分かち書き（いまの データと 同じ スタイル）。むずかしい 漢字は つかわない。
- 英語は 自然な ネイティブの 話しかた。あたたかく 元気に（Great job! / You've got it! / Let's try together.）。

## 5. ジェスチャー

| gesture | いつ | エマ先生の うごき |
|---------|------|-------------------|
| wave | greet・あいさつの ことば・See you! | 手を ふる |
| point | goal・黒板の ことば・音の 例 | 黒板を ゆびさす |
| nod | 説明の まとめ・まねして いう 文 | うなずく |
| clap | ほめる・正解・wrap | はくしゅ |
| think | check（クイズ）・なぞなぞ | あごに 手・首を かしげる |
| open_hands | 場面の 紹介・「あなたの ばん」 | 両手を ひらく |
| mime | tpr・ことばの 身ぶり（eat・jump など）・口の 形 | 動きを まねして 見せる |

## 6. 黒板（スライド）の ルール

- `title`: みじかく（日本語でも 英語でも）。W1〜12 は 日本語の 見出し（「ことば」「からだで やってみよう」「いってみよう」「クイズ」「きょうの まとめ」）、W13〜 は 英語の 見出し（Words / Let's move! / Say it! / Quiz / Today's wrap-up）。
- `items`: レッスンに ある 文字だけ（テストで チェック）。つかえるのは
  title・school.grammar・school.expressions[].en・tpr[].en・vocab[].en・phonics.focus / sounds / words・conversation.lines[].en・aiTask.targetExpressions。
  大文字小文字・文末の「. ! ?」・’ と ' の ちがいは 同じと みなす。
- 1 枚に 1〜7 個。words・repeat では 1〜2 個に しぼる（見る ところを はっきり）。
- `emoji`: 1 つ。ことばの 絵（レッスンの emoji を つかう）か 場面（🎯 ゴール・🎤 いってみよう・❓ クイズ・🌟 まとめ）。

## 7. まち時間（pauseMs）の しくみ

- 話し終わった あと、プレイヤーは「いってみよう！」と カウントダウンの 輪を pauseMs だけ 出して まつ（マイクの 音量メーターは 任意。マイクが なくても すすむ）。
- アバター動画にする ときは script.txt に `[PAUSE 3.0s]` の 印を 入れ、だまって ほほえむ 時間に する。
- めやす: 1 語 2.0〜2.5 秒 / みじかい 文 2.5〜3.5 秒 / ながい 文・じぶんの ことで いう 4〜5 秒 / からだを 動かす 3.5〜5 秒 / クイズを 考える 3 秒。
- repeat は かならず pauseMs ≥ 1,500（テストで チェック）。tpr の 合図にも pauseMs を つける。
- 「まねして」の セグメントは 1 フレーズだけに する（さいごに じぶんの ことに かえる 練習を 1 つ）。

## 8. 書きかたの 約束

- オリジナルの 文だけ（教科書の 文を 写さない）。6〜12 歳むけ。こわがらせない・だれも せめない。
- ほんとうの なまえ・じゅうしょ・がっこうの なまえを 聞かない（「ニックネームでも いいよ」）。
- お金は 円。会社名・商品名を 出さない。
- そのレッスンの ことば・表現・フォニックス・TPR・会話を つかう（ほかの 回の ことばを 黒板に 出さない）。
- 最後は「このあと（キャラ）と おはなし してみてね」で 会話ステップへ つなぐ。

## 9. テスト（tests/teacher.test.ts）

teacher が ある レッスン すべてで:
- セグメント 8 個以上、9 つの kind が ぜんぶ ある、greet で はじまり wrap で おわる
- 長さ 180〜240 秒、minutes が 3〜4
- repeat の pauseMs ≥ 1,500
- スライドの items が レッスンに ある
- subtitleJa が すべての セグメントに ある、英語の 入る セグメントに subtitleEn
- 英語の わりあいが ワールドの はんい内（W21〜 は lang がすべて en）
- run8 の 範囲（いまは L1〜210）に teacher が そろっている
