## ためしかた

### DB なし（いちばんかんたん）

```bash
npm install
npm run dev
```

→ http://localhost:3000 →「おためしで あそぶ」。いままでどおり遊べます。

### DB あり（端末ごとの おためし・ひきつぎ・パスワード再設定）

```bash
cp .env.example .env
docker compose up -d
npm run db:migrate
npm run db:seed
npm run dev
```

> この PC ではポート 5432 を別プロジェクトが使っているので、`docker-compose.yml` のポートを `"5544:5432"` に、`.env` の `DATABASE_URL` を 5544 に変えてください（`DIRECT_URL` は `"${DATABASE_URL}"` のままで OK）。

1. ふつうのウィンドウと シークレットウィンドウの両方で「おためしで あそぶ」→ レッスンを クリア → コイン・✓ が べつべつ になっていることを確認
2. 片方で「おうちの方：とうろく」→ お子さまを追加 →「ひきつぐ？」に **いいえ**
3. おうちの方ページ（暗証番号）→「おためしの きろくを ひきつぐ」→ お子さまを選ぶ → 確認 → レッスンとコインが入る
4. ログアウト →「パスワードを忘れた方」→ メールアドレスを入れる → **`.data/mail-outbox/` の HTML を開いて** リンクをクリック → 新しいパスワード → ログイン画面へ（ほかのウィンドウのログインも切れています）
5. 暗証番号パッドの「暗証番号を忘れた」→ パスワード + 新しい暗証番号
6. おうちの方ページの「LINE で学習レポート」→「今月のPDFを今すぐ送る」→ リンクから レポートの PDF（日本語がきれいに出るように なりました）

- スクリーンショット: `docs/run5/screens/p4-flow/`（通し確認・11枚）、`docs/run5/screens/p4-smoke/`（DB 停止）
- 自動チェック: `npm run check:run5-flow -- --db <使い捨てDBのURL>`（中身を書きかえるので 使い捨ての DB で）

## 公開のために用意してほしいもの

手順は **[docs/run5/DEPLOY.md](DEPLOY.md)**（チェックリストつき・約1〜2時間）と **[docs/run4/LINE-SETUP.md](../run4/LINE-SETUP.md)** にまとめました。要点だけ:

1. **アカウント**: Vercel・DB（Neon か Supabase、東京リージョン）・PDF の置き場所（Cloudflare R2 がおすすめ）・メール送信（Resend など。送信用のドメインの認証が必要）・LINE Developers
2. **ドメイン**（任意だが おすすめ）。`APP_BASE_URL` と LINE のコールバック URL に使います
3. **Vercel の環境変数**: `DATABASE_URL`・`DIRECT_URL`・`STORAGE_DRIVER=s3` と `S3_*`・`MAIL_PROVIDER`・`MAIL_FROM`・`RESEND_API_KEY`・`APP_BASE_URL`・`CRON_SECRET`（16文字以上のランダム）・LINE の5つ（一覧は DEPLOY.md の表）
4. **手元で1回だけ**: `npm run worksheets:month -- --all`（Python + reportlab が必要）→ 本番の `S3_*` を入れて `npm run worksheets:upload`、本番の DB に `npm run db:seed`
5. **LINE Developers** に Webhook URL `https://<ドメイン>/api/line/webhook` とコールバック URL `https://<ドメイン>/api/auth/line/callback` を登録（2つのチャネルは同じプロバイダーに）
6. 公開後 `https://<ドメイン>/api/health` が `ok: true`・`storage.persistent: true`・`mail.deliverable: true` になれば準備完了

## のこっている問題

- **本物のサービスには まだ一度も つないでいません**: LINE・Resend / SMTP・S3 / R2・Vercel・Neon / Supabase（キーが無いため。モック・outbox・dry-run・手元の本物の PostgreSQL で確認まで）。最初の公開のときに DEPLOY.md の「確認」を1つずつ見てください
- Docker Desktop は この実行でも起動できず、本物の DB の確認は Docker なしの PostgreSQL 16 で行いました（中身は同じ版）
- メールアドレスの「変更」はできません（LINE だけの方の「追加」だけ）
- 「暗証番号を忘れた」の LINE 本人確認は、LINE にログインしたままの端末を お子さまが使うと通ってしまいます（LINE だけの方には ほかに確かめる手段が無いため。メールアドレスを追加すれば パスワードでも確かめられます）
- レポート用フォントは Regular の1つだけ（太字なし・リポジトリが 5.7MB 増えました）
- ワークブックは ワールドを追加・変更したら 作り直して `--force` でアップロードし直す必要があります
- 前回から: 月額課金・無料体験・全クリア後の体験・収録音声・3DCG の絵は未定のまま。レッスン9画面をクリックで最後まで進める自動確認も まだです
