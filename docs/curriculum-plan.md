# Eigo Quest カリキュラム計画（12ワールド × 30レッスン = 360レッスン）

1日1レッスンで約1年。何レッスンでも進めてよいが、**毎日つづけること**をいちばん大切にする。

## 1. 基本方針

| 項目 | 方針 |
|---|---|
| 対象 | 6〜12歳（ひらがなが読める子）。英語はゼロから。**全員レッスン1から**（飛び級・プレイスメントテストなし） |
| 中心 | 日常会話の **インプット → アウトプット**（英語脳）。土台はフォニックス |
| 学校対応 | 学校の英語で扱うテーマ・表現の型に合わせる（保護者にとっての入口）。**教科書の本文・イラストは転載しない**。文はすべてオリジナル |
| 1レッスン | 先生動画 → フラッシュカード → TPR → フォニックス → 学校の表現 → 発音 → クイズ → スピードリスニング → （Phase 5）AIキャラとの会話 |
| 会話 | 毎回1つの「日常会話シーン」（`conversation`）。キャラのやりとりを聞く（インプット）→ AIキャラと話す（アウトプット、`aiTask`） |
| まとめ動画 | 毎回 2〜3分の「きょうのまとめ」（`recap.highlightsJa` などから自動生成。Phase 3） |
| テスト | 毎レッスン翌日の復習クエスト、5レッスンごとのまとめテスト、30レッスンごとのボス（既存ルールのまま） |
| 文法 | ゆっくり増やす。最初の2ワールドは「かたまり（チャンク）」で覚え、文法用語は使わない |

> **学年について**: 「小1」「小3」などは**テーマの対応先**であって、子どもの実際の学年ではない。
> 小4の子もレッスン1から始め、1日1レッスンなら約2か月で Let's Try! のテーマ（ワールド3）に入る。

### 学校教材との対応
- **ワールド1〜2（小1〜2）**: 国の教科書がないため、小学校低学年で定番のテーマ（あいさつ・色・数・からだ・きもち・動物・食べもの・天気…）。
- **ワールド3〜6（小3〜4）**: 文部科学省「Let's Try! 1 / 2」の単元テーマ。
- **ワールド7〜12（小5〜6）**: 東京書籍「NEW HORIZON Elementary 5 / 6」の単元テーマ。
- 単元名・順序は版によって変わることがある。ワールド7以降を作る前に、最新版の単元一覧と照らし合わせる（オーナー確認事項）。

## 6-11. ワールド11 のレッスン詳細（content/curriculum/lessons.json に実装済み）

- フォニックス: -ed の 3つの おと（L301 は jumped の「ト」、L302 は played の「ド」、L303 は wanted の「イド」、L304 は まざる。focus "-ed"・rule "ending-ed"）→ サイトワード was（L306）・were（L307）・said（L308）・there（L309）（rule "sight-words"）→ -er（L311 teacher の「～する ひと」、L312 baker の e を とる、L313 swimmer の もじを 2つに、L314 taller の「もっと」。focus "-er"・rule "ending-er"）→ -est（L316〜319。tallest → oldest → biggest〈もじを 2つに〉→ nicest / happiest〈e を とる・y を i に〉。focus "-est"・rule "ending-est"）→ サイトワード could（L321）・would（L322）・because（L323）・could would because（L324）。5の倍数回と L326〜330 は ふりかえり。
- サイトワードの 回の phonics.words は、その サイトワード ＋ にている ことば（was / saw / what / want、were / we / her / where、said / say / says / again、there / where / here / then、could / would / should / good、would / wood / look / foot、because / why / so / but）。rule "sight-words" の 回は「フォーカスの つづりを ふくむ」チェックの たいしょうがい（既存テストの とおり）。

## 7. データの書き方（新しいワールドを作るとき）
- `content/curriculum/lessons.json` に追記。型は `src/lib/domain/types.ts` の `LessonDef`。
- 必須: 既存フィールドすべて。新しいレッスンには `conversation`（scene / sceneJa / lines 3行以上 / aiTask）と `recap.highlightsJa` を必ず入れる。
- `conversation.lines[].speaker` は `Haru` `Riko` `Kiko` `Birimo` `Ms. Emma` のどれか。
- `aiTask` では個人情報（本名・年齢・住所・学校名など）を聞かない。名前はニックネームで OK と書く。
- `phonics.words` にはその回の `focus` のつづりを必ず含める（magic e は `a_e` のように書く。2音節語は `sun-set` のように ハイフンで わける。語末は `-st` `-s` `-ing` のように 先頭に ハイフン）。
- 1レッスン内で、同じ種類（vocab どうし・tpr どうし・phonics.words どうし）に同じ語を重複させない（学習項目 ID が重複するため）。
- `school.grade` はワールド1→小1、2→小2、3〜4→小3、5〜6→小4、7〜8→小5、9〜12→小6。
- 追加後は `npx vitest run tests/curriculum.test.ts` で検証する。
