# Phase 1 - six-year master plan
Write docs/curriculum-6year.md (Japanese) with:
- Stages and worlds: Stage 1 = worlds 1-12 (lessons 1-360, existing). Then worlds 13-40 (lessons 361-1200) grouped into stages toward A2, A2+, B1, B1+/B2 stretch.

- Yearly milestones for a child who does 5 lessons a week (and for one who does 7+).
- Mapping to school English (which lesson completes which school grade range) for the parent indicator.
- Extra input library plan (stories, read-alouds, songs/chants, free talk) and the yearly test plan.
