(school, tpr, phonics, vocab, conversation, recap, teacher, teacherScript summary). Mini tests / bosses / arenas come from the existing rules.

Run the curriculum validation, tsc, vitest, next build; commit. Record counts and one short example in docs/run7/PROGRESS.md.
