## 2. ためしかた

### A. まずは DB なしで（すぐ見られるもの）

```bash
npm install
```

```bash
npm run dev
```

- http://localhost:3000/recap/1 … きょうのまとめ動画（DB なしでも見られます。音が出ないときは ▶ を押してください）
- `docs/night/screens/characters-preview.html` をブラウザで開く … キャラクター全員・全ポーズ・エマ先生・モンスター100体
- マップ・レッスン・テストは DB が必要です。DB なしだとエラー表示になります（落ちはしません）。

### B. 全部ためす（DB あり）

```bash
docker compose up -d
```

```bash
npm run db:migrate
```

```bash
npm run db:seed
```

```bash
npm run dev
```

- http://localhost:3000 → マップ（デモユーザー「ハル」）→ Lesson 1 → 9ステップ目の「かいわ」→ 完了 → 「きょうのまとめを見る」
- **既存の DB を使っている場合も `db:migrate` と `db:seed` をもう一度**実行してください（コインの理由 `RECAP_WATCHED` の追加と、レッスン31〜360・その復習クエスト/まとめ/ボスの投入）。
- 復習クエストを当日に試したいときは `.env` に `SKIP_DAILY_LOCK=1`。
- AI会話を Claude で動かしたいときは `.env` に `ANTHROPIC_API_KEY`（無くても台本の返事で最後まで動きます）。
