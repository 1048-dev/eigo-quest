# おはようございます — run8 のまとめ（2026-11-26）

テーマは **「エマ先生が 毎回の レッスンを 3〜4 分で 教える（インプット → アウトプット）」** です。

## 何が変わったか
- **1,200 レッスン ぜんぶに エマ先生の 授業台本**（3〜4 分）を 書きました（`lesson.teacher`。むかしの 短い `teacherScript` も のこして あります）。
  - どの 回も 同じ 9 つの ながれ: あいさつ → きょうの めあて → あたらしい ことば（ジェスチャーつき）→ ちいさな 場面での 表現 → フォニックス → からだで やってみよう（TPR）→ まねして いってみよう（子どもが 話す まち時間つき）→ クイズ → まとめと ほめことば。さいごは その回の AI 会話の あいてへ つなぎます。
  - 英語の わりあいは だんだん ふえます: W1〜2 は 日本語の 説明が 中心（英語 約 30〜45%）→ W3〜6 は 半分くらい → W7〜12 は やさしい 英語が 中心 → ステージ2（W13〜20）は ほぼ 英語（97〜99%）→ **ステージ3 から（W21〜40）は 英語だけ**（日本語は 字幕だけ）。
  - 文は ぜんぶ オリジナルで、その回の ことば・表現・フォニックス・TPR・会話の キャラだけを つかいます。個人情報（ほんとうの なまえ・じゅうしょ・学校）を きかない、お金の 単位を つかわない、などは テストで 自動チェックしています。
  - 合計 24,967 セグメント。1 本 189〜239 秒（平均 約 218 秒）。
- **うごく「バーチャル教室」**（せんせいステップ）: 動画が まだ ない あいだ、アプリの 中で エマ先生が 授業します。
  - いき・まばたき・口の 形（7 種類、声に あわせて）・ジェスチャー（手を ふる・黒板を さす・うなずく・はくしゅ・かんがえる・からだで やる など）。
  - 英語は 英語の 女性の 声、日本語は 日本語の 女性の 声で 読み上げ（ブラウザの 音声合成）。0.8 / 1.0 倍、一時停止・もどる・もういちど・とばす、字幕（りょうほう／にほんご／えいご／なし）。
  - 「いってみよう！」の まち時間には カウントダウンの 輪。マイクの 音量メーターは 任意（ことわっても すすめます）。
  - 音が 出ない・DB が とまっている・スマホ でも、字幕と 時間で すすみます。
- **本物の AI アバター動画への 書きだし**（あとで 使う ため）: `npm run teacher:export` で レッスンごとに 台本（script.txt / script.json）・字幕（.vtt 日英）・黒板（slides.json）と、分数の 一覧 `exports/teacher/summary.csv` を 作ります。
  動画が できたら `npm run teacher:link` で レッスンに つなぐだけで、その回は 動画に きりかわります（コードの 変更なし。つないで いない 回は バーチャル教室の まま）。手引きは [VIDEO-VENDORS.md](VIDEO-VENDORS.md)。
- **アプリの 重さを もとに もどした**: ワールド13〜40 の フォニックス問題と バーチャル教室を あとから 読む 形に して、最初の 読みこみが /map 287 → 193 kB、/lesson 304 → 195 kB に なりました。
- **としょかん**: ステージ3〜5 の おはなし 60 話（3 問クイズつき）と チャンツ 12 曲を 追加（合計 おはなし 100 話・チャンツ 28 曲）。一覧には「いまの ステージ と つぎの ステージ」だけ 出します。
- README を run8 の 内容に あわせて 更新しました。

## のこっている問題
1. **台本の 英文の ネイティブ確認が まだ**。自動チェック（長さ・ながれの 順番・英語の わりあい・黒板の ことば・個人情報・会話の あいて）は 1,200 本 ぜんぶ 通っています が、人が 全文を 読んだのは 一部（各ブロックで ぬきとり）です。
2. **バーチャル教室の 声は ブラウザの 音声合成**なので、端末に よって 声の 自然さが ちがいます。とくに W1〜12 の 日英まじりの 文は、とちゅうで 英語の 声と 日本語の 声が いれかわります（同じ 人の 声には なりません）。
3. **字幕の 時刻は 見つもり**です。本物の 動画が できたら、字幕の 時刻を 動画に あわせる 必要が あります。
4. **動画サービスの API は まだ つないで いません**（たしかめずに API を 書かない きまり）。いまは「書きだし → 手で つくる → teacher-link で つなぐ」です。
5. 「いってみよう！」の マイクは 音量メーターだけで、ちゃんと 言えたかの 判定は していません（発音の 判定は これまでどおり 発音ステップで）。
6. 一部の 台本は 長さの めやす（205〜225 秒）を すこし こえて います（最大 239 秒。許容 180〜240 秒の 中）。
7. W40 の 黒板の 文に ビリモを「his」と よぶ ところが データの まま のこって います（声では 名前で よんでいます）。
8. この PC の ポート 3100〜3103 を 前から べつの プロセスが つかって います（スモークは 影響を 受けません）。気に なる ときは PC を 再起動して ください。
