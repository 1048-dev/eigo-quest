# 先生の 動画を AI アバター動画サービスで つくる ときの 手引き（run8 P9）

エマ先生の 授業は いま アプリの 中の「バーチャル先生」（うごく イラスト＋ブラウザの 読み上げ）が しています。
あとで 本物の AI アバター動画に したく なったら、この 手引きの とおりに すれば、**アプリの コードを かえずに** レッスンごとに 動画へ きりかえられます。

> この 文書には 特定の サービス名や 値段は 書いていません。値段・機能・利用規約は よく かわるので、**かならず 各サービスの 最新の 公式ページで たしかめて ください。**

---

## 1. ぜんたいの ながれ

```
① 書きだす        npm run teacher:export            → exports/teacher/<0001>/ と summary.csv
② 見つもる        summary.csv の 分数 × 各社の 単価（§4）
③ 動画を つくる    script.txt・slides.json・subtitles.vtt を サービスに わたす（手作業 / サービスの 一括機能）
④ アップロード      動画 lesson-0001.mp4 と 字幕 lesson-0001.vtt を ストレージ（CDN など）の 同じ 場所に おく
⑤ つなぐ          npm run teacher:link -- link 1 https://<ストレージ>/teacher/lesson-0001.mp4
⑥ たしかめる       npm run teacher:link -- check --head   → デプロイ
```

- 動画が つながった レッスンは「せんせい」ステップで 動画が 再生され、となりに .vtt が あれば 日本語字幕が つきます。
- つながって いない レッスンは これまでどおり バーチャル先生が 授業します（まぜて つかえます。少しずつ ふやせます）。

## 2. 書きだされる ファイル（scripts/teacher-export.ts）

| ファイル | 中身 | つかいみち |
|---|---|---|
| `exports/teacher/0001/script.txt` | 台本。`#` で はじまる 行は メモ（読まない）。`[PAUSE 2.5s]` は 子どもが まねする「まち時間」 | サービスの 台本の 入力らん（`#` 行は けして わたす。PAUSE は サービスの「間（ま）」の 機能に おきかえる） |
| `script.json` | セグメントごとの データ（話す 文・言語ごとの かたまり `parts`・ジェスチャー・黒板・見つもりの 時刻） | API や 一括作成で 機械的に わたす とき |
| `subtitles.vtt` | 日本語＋英語の 字幕（WebVTT）。`subtitles.ja.vtt`・`subtitles.en.vtt` も ある | 動画と 同じ 名前（`lesson-0001.vtt`）で となりに おく |
| `slides.json` | 黒板（スライド）の 中身と 出す 時刻 | 動画の うしろや よこに スライドを 出せる サービスで つかう |
| `exports/teacher/summary.csv` | レッスンごとの 長さ（秒・分・切り上げ分）と 合計（さいごの TOTAL 行） | 見つもり（§4）。Excel で そのまま ひらける（UTF-8 BOM つき） |

- コマンド: `npm run teacher:export`（全部）、`-- --from 1 --to 30`（はんい）、`-- --only-script`（台本が 書けた レッスンだけ）、`-- --summary-only`。
- 何度 やっても 同じ 結果です。台本を なおしたら もう一度 書きだして ください。
- 台本（3〜4 分）が まだ ない レッスンは、バーチャル先生と 同じ「自動の 授業」（約 2〜3 分）が 書きだされ、summary.csv の `source` が `auto` に なります。
  **本番の 動画は `source = script` の レッスンだけで つくる のが おすすめです**（`--only-script`）。
- 字幕の 時刻は「読む はやさの 見つもり」です。できあがった 動画とは ずれるので、サービスの 字幕機能で 作りなおすか、字幕ツールで 時刻を あわせて ください。
  日本語字幕と 英語字幕の 文の 数が ちがう セグメントは、1 つの 字幕の 中で 日本語と 英語が すこし ずれる ことが あります。
- `exports/teacher/` は 約 7,200 ファイルに なるので git には 入れません（summary.csv だけ 入れて あります）。

## 3. サービスを えらぶ ときに 見る ところ

### 声（いちばん だいじ）
- **日本語と 英語の 両方が 自然か。** エマ先生は 1 つの 文の 中で 日本語と 英語を きりかえます（W1〜12）。
  「同じ 声の まま 言語が かわる」ことが できるか、英語の ところが カタカナ英語に ならないか、日本語の ところが 外国なまりに ならないかを、**L1 の script.txt で ためして** きいて ください。
- 英語は ネイティブの 発音（アメリカ英語 en-US を 想定）。子どもが まねする お手本なので、ここは 妥協しない。
- こども向けの「ゆっくり・はっきり・あかるい」話しかたが できるか（話す 速さの 調整・感情の 調整）。
- 「間（ま）」を 秒数で 入れられるか（`[PAUSE 2.5s]`。1 レッスンに 10〜20 か所 あります）。
- 発音の 辞書（読みかたの 登録）が あるか（`I'm ～.` の「～」や、フォニックスの 音 /æ/ など）。

### 口の 動き・見た目
- リップシンクが 日本語でも 英語でも 自然か（日本語は 口の 形が ずれやすい）。
- ジェスチャー（手を ふる・指さす・うなずく・拍手）を 台本から 指定できるか。`script.json` の `gesture` を つかえます。
- 背景や スライド（黒板）を 動画に 入れられるか（`slides.json`）。入れられなければ 先生だけの 動画に して、黒板は アプリ側で 出す 方法も あります。
- 画面の 大きさ・形（16:9 が 基本。スマホで 見やすいか）。

### 権利・ライセンス（かならず 文書で たしかめる）
- **商用利用**が できるか（有料の アプリ・サービスの 中で 子どもに 見せる）。プランによって ちがう ことが 多い。
- **オリジナルの アバター**（エマ先生の 見た目）を つくれるか、その アバターの 権利は だれの ものか、解約したら つかえなく なるか。
  ストックの アバター（ほかの 会社も つかえる 顔）を つかう ときは、ほかの 製品と かぶって も よいか 考える。
- 実在の 人を もとに した アバターや 声を つかう ときは、その 人の 同意と 契約が 必要。
- できた 動画を **自分の ストレージに ダウンロードして 配信して よいか**（サービスの 中でしか 再生できない 契約だと、このアプリには つかえません）。
- 解約した あとも、それまでに つくった 動画を つかいつづけて よいか。
- 子ども向けで あることを つたえて、規約上 問題ないか（データの あつかい・プライバシー）。

### 値段と 量
- 料金の しくみ: 「1 分 あたり」「月の クレジット」「1 本 あたり」など。**切り上げ**（1 分 未満は 1 分 など）が あるかで 合計が かわります（§4）。
- 1,200 本・数十時間を つくれる プランが あるか。月の 上限、まとめて つくる ときの 割引。
- 作りなおし（台本を なおして もう一度）にも 料金が かかるか。

### API・一括作成（バッチ）
- 台本を まとめて 入れて 一括で つくれるか（CSV・API など）。1,200 本を 手作業で つくるのは 大変です。
- API が ある ときは、**公式の ドキュメントを 読んでから** `src/lib/teacherVideo/` に プロバイダーを 足して ください（`TeacherVideoProvider` の `generate(lesson)` を 実装する）。
  このリポジトリには まだ どの サービスの API も 書いて いません（たしかめずに API を 書かない きまり）。
- できあがりの 通知（webhook など）と、失敗した ときの やりなおし。

### ためしかた（おすすめ）
1. 候補を 2〜3 社に しぼる。
2. 各社で **L1（W1・日本語多め）・L300 前後（W10・英語多め）・L700 前後（W24・英語だけ）** の 3 本を ためしに つくる（無料枠や お試しプランで）。
3. 子ども（できれば 対象年れいの 子）に 見て もらい、「まねしたく なるか」「ききとれるか」を たしかめる。
4. 値段・権利・API を 表に して くらべて きめる。

## 4. summary.csv から 費用を 見つもる

summary.csv の 列:

| 列 | 意味 |
|---|---|
| `totalSeconds` / `totalMinutes` | 1 本の 長さの 見つもり（話す 時間＋まち時間＋きりかえ） |
| `minutesRoundedUp` | 1 本ずつ 分を 切り上げた 値（1 分 未満を 1 分と 数える サービス用） |
| `speechSeconds` / `pauseSeconds` | 話して いる 時間 / まち時間（まち時間も 動画の 長さに 入ります） |
| `source` | `script`（3〜4 分の 台本） / `auto`（自動の 授業） |
| `englishPercent` | 英語で 話す 時間の わりあい（声の 設定の 参考） |
| さいごの `TOTAL` 行 | ぜんぶの 合計（`totalMinutes`・`minutesRoundedUp`） |

見つもりの しかた:

```
費用 ≒ 合計の 分数 × 1 分 あたりの 単価 × (1 + 作りなおしの わりあい)
```

- 1 分 あたりの 単価は、えらんだ プランの **最新の 料金ページ** で たしかめて ください（この 文書には 書きません）。
- 「1 本ずつ 切り上げ」の サービスなら `minutesRoundedUp` の 合計を、秒単位なら `totalMinutes` の 合計を つかいます。
- 月の クレジット制なら「合計の 分数 ÷ 1 か月の 分数 = 必要な 月数」で 考えます。
- 作りなおし（声の 調子・まちがい）に そなえて **10〜20% 多めに** 見て おくと 安心です。
- 長さは 読む はやさからの 見つもりです。実際の 動画は ±10% くらい ちがう ことが あります（声の 速さの 設定で かわる）。
- 例（2026-11-26 に 書きだした とき）: 1,200 本 合計 約 2,906 分（約 48.4 時間）、切り上げ 合計 3,596 分。
  ただし いまは 台本が ある レッスンが L1〜30 だけで、のこりは 自動の 授業（約 2〜3 分）です。
  **全レッスンの 台本（3〜4 分）が そろうと、合計は 約 3,600〜4,800 分（60〜80 時間）に なる 見こみ**です。台本が そろってから もう一度 書きだして 見つもって ください。
- 一度に ぜんぶ つくらず、**ステージ 1（W1〜12）から 順に** つくると、費用も 確認の 手間も 分けられます（`--from` / `--to`）。

## 5. 動画を つなぐ（scripts/teacher-link.ts）

動画の 場所は **content/teacher-videos.json**（マニフェスト）に 書きます。DB では なく JSON に した 理由:
- DB が ねて いても（おためし・オフライン）同じ 動画が 出る
- レッスンの データと 同じく git に 変更が のこり、もどせる
- 1,200 本 ぜんぶ 入っても 約 100KB

```
npm run teacher:link -- link 12 https://<ストレージ>/teacher/lesson-0012.mp4
npm run teacher:link -- link-range --from 1 --to 30 --pattern "https://<ストレージ>/teacher/lesson-{nnnn}.mp4"   # {nnnn} = 0001、{n} = 1
npm run teacher:link -- unlink 12
npm run teacher:link -- list
npm run teacher:link -- check --head      # URL に アクセスして 動画と 字幕が あるか たしかめる（1 本 10 秒まで）
（どれも --dry で 書かずに 表示だけ、--note "メモ" で メモを のこせる）
```

- URL は `https://` か、`/`（public/ の 下）から はじまる ものだけ うけつけます。
- 字幕は 動画と 同じ 名前の `.vtt` を 同じ 場所に（`lesson-0012.mp4` → `lesson-0012.vtt`）。`exports/teacher/0012/subtitles.vtt` の 名前を かえて アップロード して ください。
  ちがう ドメイン（CDN）から 配信する ときは、動画と 字幕に CORS（`Access-Control-Allow-Origin`）の 設定が 必要です（プレイヤーは `crossOrigin="anonymous"` で 読みます）。
- つないだ あと `git commit` して デプロイすると 反映されます。
- `src/lib/teacherVideo/index.ts` の 手動プロバイダー（`manual`）は、つないで あれば 動画の URL を、なければ「つぎに すること」を かえします。
  将来 サービスの API を つかう ときは、同じ `TeacherVideoProvider` の 形で プロバイダーを 足し、できた URL を 同じ マニフェストに 書きこみます。
