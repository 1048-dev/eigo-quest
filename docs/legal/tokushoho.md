# 特定商取引法に基づく表記（下書き）

> この文書は、専門家（弁護士など）に確認してもらう前の **下書き** です。【要確認】と書いた ところは、運営者の 本当の 情報を 入れるか、専門家の 判断が 必要な ところです。
> 現在の本サービスには決済機能がありません。有料での提供を始める前に、すべての【要確認】を埋めてください。

| 項目 | 内容 |
| --- | --- |
| 販売事業者 | 【要確認：運営者の名称（個人の場合は氏名）】 |
| 運営統括責任者 | 【要確認：責任者の氏名】 |
| 所在地 | 【要確認：住所】 |
| 電話番号 | 【要確認：電話番号】（お問い合わせは、できるだけメールでお願いします）【要確認：個人事業者が「請求があれば遅滞なく開示する」とする書き方を使うかどうか】 |
| メールアドレス | 【要確認：お問い合わせ用のメールアドレス】 |
| サービスの名称 | 英語クエスト（こども向け英語学習サービス） |
| 販売価格 | 【要確認：月額 ○○円（税込）など。プランごとの価格】 |
| 商品代金以外に必要な料金 | インターネットの通信料（お客さまのご負担です） |
| 支払い方法 | 【要確認：クレジットカードなど】 |
| 支払い時期 | 【要確認：例「お申し込みのときに初回分、その後は毎月の更新日に自動で請求」】 |
| 無料のおためし期間 | 【要確認：有無・期間・無料期間のあとに自動で有料になるかどうか】 |
| サービスの提供時期 | お支払いの手続きが終わったあと、すぐにご利用いただけます |
| 申し込みの有効期限 | 【要確認】 |
| 解約（定期契約の停止） | 【要確認：解約の方法（保護者向けページから など）と、解約が反映される時期（例「次の更新日の前日までに解約すると、次の請求は行いません」）】 |
| 返品・キャンセル・返金 | デジタルのサービスのため、お支払い後の返金はお受けしていません。【要確認：法令で必要な場合・運営者の不具合でサービスを使えなかった場合の扱い】 |

| 特別な販売条件 | お申し込みは保護者の方が行ってください。【要確認：未成年者の申し込みの扱い】 |

## 補足

- 定期購入（サブスクリプション）の場合は、申込画面の最終確認で、価格・支払い時期・契約期間・解約の方法をはっきり表示する必要があります（特定商取引法 第12条の6）。【要確認：申込画面の表示内容】
- 表示する内容は、事業の形（個人・法人）によって変わることがあります。【要確認】
