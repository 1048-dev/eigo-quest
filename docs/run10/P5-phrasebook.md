# Phase 5 - one canonical way to say things
1. docs/phrasebook.md: for each function (greetings, goodbyes, asking/telling name, feelings, praise, encouragement, classroom instructions, asking to repeat,
   turn-taking, agreeing/disagreeing, thanking, apologizing, asking for things, giving opinions/reasons, etc.) and each stage: the canonical American English form,
   allowed variants and the stage where each variant is introduced on purpose, and forms to avoid (with reasons, e.g. British, stiff, textbook-only, unnatural).
2. Add a phrasebook rule to english:lint that flags non-canonical forms outside their intended stage.
3. Apply it to ALL lessons, teacher scripts, conversations, recap, library, tests, UI strings and templates. Keep meaning and level. Log changes in docs/run10/changes/phrasebook.md.
