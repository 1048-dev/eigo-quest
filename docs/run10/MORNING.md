## 3. なおした おもな バグ
- 英文を えらぶ 問題が **2 択**に なる（172 か所）→ 4 択に。
- 年号（1600 など）を **数字の まま** 読みあげ → 「sixteen hundred」。
- かいわで 目標を 言っても「つかった」に ならない／お手本が「It's in ....」の まま → 判定と お手本を なおした。
- ワークブックの こたえが「June → J」など（6,000 か所 以上）→ 小文字・数の 回は「アプリで れんしゅう」。
- 発音の 結果で おなじ ことばが 2 回 ある 文の ○× が ずれる（542 画面）。
- **電波が ない とき** 書きとりが いつも ✕・テストの さいごで すすめない → 端末で 採点・「もう一回 さいてん」。
- 色が うすい・読みあげの 名前が ちがう（アクセシビリティ）。
（ぜんぶの 一覧は QUALITY.md の 3 章）

## 5. ためしかた
```bash
npm install
npm run check:all              # ぜんぶ（約 48 分）。DB は 自動で 用意（Docker か embedded-postgres・ポート 5544）
npm run check:all -- --skip e2e   # いそぐ とき（約 25 分）
```
けっかは 画面の 表と `docs/run10/report/latest.md`。FAIL が あれば 終了コード 1 です。ほかの 重い しごとと 同時に うごかさないで ください（時間切れの 原因に なります）。

## 6. 正直な のこりの 限界（くわしくは QUALITY.md の 5 章）
- ブラウザで クリックして さいごまで すすめたのは **40 レッスン**（のこりは データと サーバー描画で ぜんぶ）。
- ブラウザは **Chromium だけ**。iPhone / Android / iPad の 実機は まだ。
- **音声の 読みあげと マイクは テスト用の にせもの**。本物の 声・こどもの 発音の 認識は 実機で 人が 確認する 必要が あります。
- 本物の AI・メール送信・LINE 送信は しらべて いません（キーなし・outbox・dry-run）。
- 英語の 自然さは lint の きまりの 範囲 だけ。**ネイティブの 先生に 一度 読んで もらう** ことを おすすめします。
- **本番の ワークブック PDF は 作りなおしが 必要**: `npm run worksheets` → `npm run worksheets:upload`。

## 7. 決めて ほしい こと
1. TPR の「Make an X」や「mistake」の 絵文字が ❌ で、まちがいの おしらせ（❌）と まぎらわしい かも しれません。🙅 など に かえますか？（いまは そのまま）
2. 実機（iPhone・Android・iPad）での 確認と、ネイティブの 先生の 読みあわせを いつ するか。
3. ワークブック PDF の 作りなおしと アップロードを いつ するか。
