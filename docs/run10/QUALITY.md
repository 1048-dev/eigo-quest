## 5. 正直な のこりの 限界

1. **クリックで さいごまで すすめたのは 40 レッスン**（1 ワールド 1 つ）。1,200 ぜんぶを クリックすると 約 17 時間 かかるため。のこりは データ（Phase 2）と サーバー描画（Phase 3）で ぜんぶ しらべて いますが、ブラウザでの 動き（音・タイマー・アニメーション）は 40 レッスン ぶん だけです。
2. **ブラウザは Chromium だけ**。iPhone の Safari・Android 実機・iPad 実機では ためして いません。
3. **音と マイクは にせもの**。読みあげ（speechSynthesis）と 音声認識は テスト用の かわりを 入れて います。実際の 声の 聞こえかた・認識の 正しさ（こどもの 発音）は 人が 実機で たしかめる 必要が あります。
4. **AI（かいわ・書きとりの AI 採点）は キーなし**で ためしました（台本エンジンと ルール採点）。本物の AI の 返事は しらべて いません。
5. **メールは outbox（送らない）・LINE は dry-run**。本物の 送信は していません。
6. **英語の 自然さの 最終判断は 人では ない**。lint は 決めた 形だけ を 見つけます。リストに ない 不自然な 文は 見のがす 可能性が あります。warn 464 は run9 で「わざと」と 決めた もの（error に して いない）。ネイティブの 先生に 一度 読んで もらうのが おすすめです。
7. **アクセシビリティは 26 画面・スマホの 大きさ だけ**。axe で 見つけられる 問題だけで、スクリーンリーダーを 人が つかった 確認では ありません。
8. **seed は 5 つ**。問題の ならびは 乱数なので、すべての ならびかたを ためした わけでは ありません（ただし 項目 × 形式 は ぜんぶ）。
9. **本番の ワークブック PDF は まだ 古い**。こたえの 小文字などを なおしたので、`npm run worksheets` → `npm run worksheets:upload` で 作りなおす 必要が あります。
10. **時間の 長い テストの ゆれ**: 重い とき（確認を 2〜3 本 同時に うごかした とき）は 時間切れに なる ことが ありました。check:all は 1 本 だけで 動かして ください。Windows で 1 回だけ 一時ファイルの エラー（テストの 中身では ない）が 出ました。
11. 本番の DB（ポート 5432）には さわって いません（べつの プロジェクト）。確認用の DB は ポート 5544 の 使いすて です。

## 6. `npm run check:all` の うごかしかた

```bash
npm install            # はじめて だけ
npm run check:all      # 11 ステップ ぜんぶ（約 48 分）
```

- **Docker が あれば** 使いすての Postgres（ポート 5544・コンテナ名 eq-check-db）を 自動で 起動・削除します。**なければ** npm の embedded-postgres を 自動で つかいます。じぶんで DB を 用意する 必要は ありません。ポート 5432 は つかいません（コードで こばみます）。
- python と reportlab が あれば ワークブックの PDF も 作って しらべます（なければ その部分 だけ とばします）。
- けっかは 画面の さいごの 表と **docs/run10/report/latest.md**。ステップごとの ログは `.data/check-all/<name>.log`。
- **FAIL が 1 つでも あれば 終了コード 1**。表の note と ログを 見て ください。

べんりな オプション:
```bash
npm run check:all -- --list                 # ステップの 一覧
npm run check:all -- --only tsc,vitest      # えらんだ ステップ だけ
npm run check:all -- --skip e2e             # E2E を とばす（約 25 分）
npm run check:all -- --strict               # SKIP も 失敗に する
```

ステップを 1 つずつ: `npm run english:lint`・`npm run check:data`・`npm run check:render`・`npm run check:e2e`・`npm run check:a11y`・`npm run check:links`・`npm run check:bundle`。
