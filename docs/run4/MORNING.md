## かわったこと

1. **おためしの きろくの ひきつぎ**
   - おためしモードで遊んだ分（クリアしたレッスン・合格したテスト・コイン・遊んだ日）を、その端末のブラウザに記録するようにしました
   - 保護者が登録・ログインして「だれが あそぶ？」で子どもを選ぶと、**1回だけ**「おためしで あそんだ きろくを ひきつぐ？」と聞きます（レッスン数・コインを表示）。「はい」でその子に たし合わせ、「いいえ」なら もう聞きません
   - 共有のデモユーザーの DB の記録は使わず「この端末で遊んだ分」だけを送ります（ほかの家の記録がまざらないように）。コインはサーバーで上限をかけます
2. **アバター選択**
   - お子さまの追加・編集で ハル・リコ・キコ・ビリモ から選べます（選ばなければ きょうだいと かぶらない顔）
   - 子ども自身もヘッダーの顔をタッチして変えられます（暗証番号なし）
   - 「だれが あそぶ？」・ヘッダー・おうちの方ページで同じ顔を表示
3. **LINE でログイン（保護者）**
   - はじめての LINE → そのまま新規登録 → 暗証番号を決める画面（`/setup-pin`）→ お子さまを追加
   - メールで登録ずみの方は「おうちの方」→「LINE の連携」で連携・解除
   - キーが無い間はボタンが出ません（いまの状態）
4. **毎月の学習レポート（PDF）を LINE で届ける**
   - お子さまごとの「学習レポート（A4 1ページ）」と「いまのワールドの 1か月ワークブック」
   - LINE は PDF を直接送れないので、「PDFをひらく」ボタン付きのメッセージで**ダウンロードページ**（30日有効のリンク・ログイン不要）を送ります
   - おうちの方ページに「LINE で学習レポート」（毎月の配信のオン/オフ・今月のPDFを今すぐ送る）
   - 毎月の一斉配信は `npm run line:monthly`（毎月1日に cron で実行する想定）
   - **キーが無い間は dry-run**: LINE には何も送らず、`.data/line-outbox/` に送るはずだったメッセージと PDF を書きます
5. **全体チェック**: DB 停止のスモーク、本物の DB（Docker の使い捨て PostgreSQL・ポート 5544）での通し確認（ブラウザで おためし → 登録 → ひきつぎ → レポートの PDF まで 22項目）すべて OK。セキュリティの見直しで6件直しました（LINE の state cookie に署名、ほかのサイトから LINE ログインを始めさせない、webhook の巨大な本文、イベント時刻の検証、ファイルの場所の確認、連携解除でリンクを無効に）
6. README を今の状態に更新

## ためしかた

### DB なし（いちばんかんたん）

```bash
npm install
npm run dev
```

→ http://localhost:3000 →「おためしで あそぶ」。いままでどおり遊べます（LINE のボタンは出ません）。

### DB あり（ひきつぎ・アバター・レポートの dry-run）

```bash
cp .env.example .env
docker compose up -d
npm run db:migrate
npm run dev
```

> この PC ではポート 5432 を別プロジェクトが使っているので、`docker-compose.yml` と `.env` のポートを 5544 などに変えてください。

## LINE のために用意してほしいもの

手順は **[docs/run4/LINE-SETUP.md](LINE-SETUP.md)** にまとめました。要点だけ:

1. **公開された HTTPS の URL**（本番のドメイン）。LINE からの webhook とダウンロードページに必須で、`localhost` では動きません
2. LINE Developers で**1つのプロバイダー**を作り、その中に
   - **LINE 公式アカウント（Messaging API チャネル）**: Webhook URL `https://<ドメイン>/api/line/webhook`
   - **LINE ログインのチャネル**: コールバック URL `https://<ドメイン>/api/auth/line/callback`、公式アカウントをリンク、「公開」に切りかえ
   - ※ 2つのチャネルが別のプロバイダーだと、レポートが届きません
3. `.env` に6つの値: `LINE_LOGIN_CHANNEL_ID`・`LINE_LOGIN_CHANNEL_SECRET`・`LINE_LOGIN_CALLBACK_URL`・`LINE_MESSAGING_CHANNEL_ACCESS_TOKEN`・`LINE_MESSAGING_CHANNEL_SECRET`・`APP_BASE_URL` → サーバーを起動しなおす
4. 毎月1日の朝に `npm run line:monthly` を実行する cron
5. 公式アカウントの料金プラン（無料プランは月の送信数に上限。保護者1人につき毎月1通）

## のこっている問題

- **本物の LINE チャネルでは まだ一度も試していません**（チャネルが無いため。LINE のサーバーをまねたテストと、ダミーの値での本物のサーバー確認まで）
- パスワード・暗証番号を忘れたときの再設定がない（メール送信は後日の予定どおり）。LINE だけで登録した方が あとからメール・パスワードを追加する機能もありません
- おためしモードは全員で1人のデモユーザーを共有しているため、だれかが先にクリアしたレッスンは、別の端末ではコイン +0 になります（引き継ぐコインも 0）
- 「いいえ」を選んだ端末では、あとから引き継ぐ手段がありません
- PDF はサーバーのフォルダに保存（サーバー1台が前提）。レート制限もメモリ内
- レッスンの9つの画面をクリックで最後まで進める自動確認はしていません（レッスン完了のリクエストで代用）
- 前回から: 月額課金・全クリア後の体験・収録音声・3DCG の絵は未定のまま
