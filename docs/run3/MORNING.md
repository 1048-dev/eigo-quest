## ためしかた

### DB なし（いちばんかんたん）

```bash
npm install
npm run dev
```

→ http://localhost:3000 → スタート画面で「おためしで あそぶ」。
登録・ログインを押すと「ただいまアカウント機能を利用できません」と出て、おためしへ進めるのが正しい動きです。

### DB あり（保護者アカウントをためす）

```bash
cp .env.example .env
docker compose up -d
npm run db:migrate
SEED_DEMO_PARENT=1 npm run db:seed
npm run dev
```

（PowerShell では `$env:SEED_DEMO_PARENT="1"; npm run db:seed`）

1. http://localhost:3000 →「おうちの方：ログイン」→ `demo-parent@example.com` / `demo-pass-1234`
   （または「とうろく」で新しく作る → そのままお子さまを追加）
2. 「だれが あそぶ？」で子どもを選ぶ → マップでレッスン
3. ヘッダーの「おうちの方」→ 暗証番号 `1234` → ようす・回数制限・編集・退会など

> 注意: この PC ではポート 5432 を別プロジェクトのコンテナ（gamblex-db）が使っているため、`docker compose up -d` がぶつかって起動できませんでした。夜間の確認は別ポート（5544）の使い捨て PostgreSQL で行いました。止めるか、`docker-compose.yml` と `.env` のポートを変えてください。
