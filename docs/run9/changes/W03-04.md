## 共通の きめごと（ブロック全体）
1. 2択クイズの 英語字幕「Here you are. or Thank you.?」→「Here you are. / Thank you.」（W01-02 と おなじ）。say の「… それとも Thank you.?」は 2つめの 記号を とる
2. 日本語の なかの 英語: 「Thank you.。」「Yes, I do.、」「How many balls?！」の ような 2重の 記号は 英語がわだけ のこし、あとに 日本語が つづく ときは スペース。日本語字幕の 2択「Thank you.？ What do you want?？」→「Thank you. / What do you want?」
3. 話しことばの 2択「Hint, please? Or, I know?」→「Hint, please? Or I know?」（Or の あとの コンマと 文の なかの 大文字を とる。L97〜100 で レビュアーが なおした 形に そろえた）
4. L62「And you?」→「How about you?」（A+C＋lint。スタイルガイド §5「And you? だけ」は さける）。文型・表現・会話・スライド・字幕・teacherScript・まとめ ぜんぶ。**学習項目 ID が かわる**（L0062 の 表現「I'm Kiko. And you?」→「I'm Kiko. How about you?」。この 1項目だけ 記録が あたらしく なる）
5. L88 TPR「Give a thumbs up.」→「Give a thumbs-up.」（名詞の thumbs-up は ハイフン。L118 と そろえた）。**学習項目 ID が かわる**（L0088 の TPR）
6. L87 aiTask の 1文 9語 →「One is happy. Three is sleepy. Six is hungry.」（ステージ1 は 8語まで。会話の 1行目と おなじ 形）
7. イギリスふうの ほめことば「Brilliant!」（L70・L79・L96・L117）→「Awesome! / Perfect! / Way to go!」、「Lovely job!」（L99）→「Nice job!」、「Lovely reading today!」（L106）→「Great reading today!」（W01-02 の L59 と おなじ きめかた。A+C）
8. クイズの こたえで 質問を くりかえす とき「How many balls!」「Who are you!」「Are you a pig!」→「?」（TTS が さげて よむ・ブタだと からかって いる ように きこえる）
