## 共通の きめごと（ブロック全体）
1. 2択クイズの 英語字幕「Nice to meet you. or Go!?」のような 終わりの 記号 2つ → 「Nice to meet you. / Go!」（ほかの 字幕と おなじ「/」区切り）。「How many? three or four?」の 小文字は 大文字に
2. 英語の「…」→「...」
3. 日本語の なかの 英語: 「Yes, I do.！」の ような 2重の 文末記号は 英語がわだけ のこす。「windy.かぜ」の ような すきまの ない ところに スペース（TTS が 1語に よまない ように）
4. L3「I'm fine, thank you.」→「I'm fine, thanks.」（A・B・C。教科書の 決まり文句。学校の テストに でる fine は のこし、thanks で かるく 自然に。会話・スライド・字幕・まとめ・teacherScript も あわせた。会話エンジンの 予備の 会話も 同じに）。**学習項目 ID が かわる**（L0003-E2。この 1項目だけ 記録が あたらしく なる）
5. L23 TPR「Hug.」→「Hug yourself.」（A・B。じぶんを ぎゅっと する 動作の 指示として 自然に）。**学習項目 ID が かわる**（L0023 の C）
