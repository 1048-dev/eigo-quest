# Eigo Quest 6年カリキュラム計画（40ワールド × 30レッスン = 1,200レッスン）

小学1年から6年まで、6年間つかい続けられるカリキュラム。既存の 360 レッスン（docs/curriculum-plan.md）は **ステージ1** としてそのまま残し、
レッスン 361〜1200（ワールド13〜40）を **ステージ2〜5** として積み上げる。

> この文書は run7 の計画書。ワールド13以降の各ワールドを書くときは、この文書の「§10 ワールド詳細」を正とする
> （細部は書きながら調整してよい。変えたときは docs/run7/PROGRESS.md に記録する）。

## 1. 基本方針

| 項目 | 方針 |
|---|---|
| 期間 | 小1〜小6 の 6年。**週5レッスン × 年40週 = 年200レッスン** で、ちょうど 6年で 1,200 レッスン |
| 区切り | **学年ではなくレベル（ステージ）で区切る**。全員レッスン1から。速く進む子は速く進んでよい（学校より先に進んでよい） |
| ゴール（理想） | 小1で始めた子が、小6で「ネイティブの小6と自然に話せる」 |
| ゴール（保護者への約束） | **小6で CEFR A2〜B1 の会話力**（英検3級〜2級のレベル感）。追加インプット（§7）をたくさん使う子はさらに上（B1+〜B2 の入口）をめざす |
| 中心 | 日常会話の インプット → アウトプット（英語脳）。毎回の会話シーン（`conversation`）と AI キャラとの会話（`aiTask`） |
| 教材の文 | **すべてオリジナルの自然な英語**。教科書・市販教材の文は使わない。話題は 6〜12 歳にふさわしいものに限る（学年が上がっても） |
| 学校との対応 | 保護者向けの目安として「学校の英語 ○年生の内容まで修了」を表示する（§6） |
| 月のレポート | **20 レッスンごと**（平日ペースで約1か月）に 1 枚の PDF。1,200 レッスンで 60 回 |
| 毎日の追加インプット | レッスンの外に「えいごの としょかん」（段階別のおはなし・読み聞かせ・歌とチャンツ・AI とのフリートーク）。**流暢さのいちばんの近道**（§7） |
| 年に1回の力だめし | 英検に似た形式（問題はすべてオリジナル）。保護者に伸びを見せる（§8） |
| ルール | 1 レッスン = 既存のスキーマのまま（school / tpr / phonics / vocab / conversation / recap / teacher / teacherScript）。5 レッスンごとのまとめテスト・30 レッスンごとのボスは既存ルールのまま |

### 1-1. 先生の台本（teacher）の英語の割合

| ステージ | 先生の台本 | 会話シーン | AI 会話の goalJa |
|---|---|---|---|

### 1-2. キャラクター
- 会話の話し手は既存の 5 人（`Haru` `Riko` `Kiko` `Birimo` `Ms. Emma`）のまま。スキーマを変えずに済み、子どもにもなじみがある。
- 物語: ワールド12 で「えいごの王国」にたどりついた4人とエマ先生は、ビリモが見つけた「まだ地図にない せかい」の地図をもとに、新しい旅に出る。
  ステージが上がるごとに、行く場所が遠く・話す相手が多様になり、子どもの成長とキャラの成長が重なるようにする。
- 外国の友だち・お店の人など「その場の人」は、ビリモやエマ先生が役を演じる（ごっこ遊び・ロールプレイ）形で出す（新しい話し手は増やさない）。

- 英検のめやすは「その級の **会話・リスニング・読む力の感じ**」の目安で、合格を保証するものではない（英検2級の語彙は約 5,000 語と多い。本カリキュラムは会話力を優先する）。
- 語彙は「理解できる語」の累計。言える語（産出語彙）はその 6〜7 割をめやすにする。1 レッスンの新出語は 3〜5 語＋表現。
- 1 レッスンの時間はステージ1と同じ 15〜20 分。ステージ3以降は「読む」「書く」パートを少し長くし、TPR を短くする。

## 3. ステージ詳細

### ステージ1（ワールド1〜12・L1〜360・Pre-A1 → A1）— 既存
- 内容は docs/curriculum-plan.md のとおり（変更しない）。学校の小1〜小6 のテーマ、フォニックス（26 音 → CVC → ダイグラフ → ブレンド → マジック e → 母音チーム → r のつく母音 → 語尾・多音節・音読）。
- できるようになること: あいさつ・自己紹介・好きなもの・できること・ほしいもの・時刻・場所・過去のできごと（went / saw / ate / was）を短い文で言える。5W1H の質問ができる。

### ステージ2（ワールド13〜20・L361〜600・A1 → A2）「ひろがる せかい」

| 観点 | 目標 |

## 9. データと技術の方針（1,200 レッスンでも速く）

- レッスンはワールドごとの JSON（`content/curriculum/worlds/world-01.json` 〜 `world-40.json`）に分け、サーバーで読み込む。ブラウザにカリキュラム全体を送らない（P2）。
- 小さな索引（タイトル・ステージ・ワールド）だけを持ち、地図や一覧はそれを使う。
- 各レッスンの必須項目は既存と同じ（`docs/curriculum-plan.md` §7 のルール）。追加で任意の `stage`（1〜5）と `level`（"Pre-A1" / "A1" / "A2" / "A2+" / "B1" / "B1+"）を持てる。
- `school.grade` はステージ2 以降、§6 の表に合わせて「中1」「中2」「中3」「高校初級」「高校」とする（保護者向けの目安）。
- `conversation.lines[].speaker` は既存の 5 人。`aiTask` では個人情報（本名・年齢・住所・学校名など）を聞かない。
- `phonics.rule` はステージ2 以降に新しい値（"spelling" / "morphology" / "prosody" など）を使ってよい。そのときはクイズの出し方（questions.ts）を P2〜WORLD 作業で追加し、テストで確認する。

## 11. 書くときのチェックリスト（WORLD.md の作業用）
- そのステージの文法・語彙・先生の英語の割合（§1-1・§3）に合っているか。前のワールドで出ていない型をいきなり使っていないか。
- 文はすべてオリジナルで自然な英語か（教科書・市販教材・有名な物語の文をそのまま使っていない）。昔話・神話はオリジナルの語り直し。
- 話題が 6〜12 歳にふさわしいか（防災・社会の話題はこわがらせない、一方の立場に寄せない）。
- `aiTask` で個人情報（本名・年齢・住所・学校名・パスワードなど）を聞かない。ネットの話題では「個人情報を出さない」を正しく教える。
- 会社名・商品名・実在の有名人の名前を出さない（伝記は架空の人物、または「ある科学者」のように一般化する）。
- 5 の倍数回はまとめ、30 回目はグランドレビュー。まとめテスト・ボスは既存ルールのまま。
- 各ワールドを書き終えたら、カリキュラム検証・tsc・vitest・next build を通し、PROGRESS.md に件数と例を 1 つ記録する。
