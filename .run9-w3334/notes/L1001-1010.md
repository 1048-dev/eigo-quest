#### Block-wide notes
- **teacherScript still narrates Ms. Emma in the third person** ("Ms. Emma takes us...", "Ms. Emma says, ...", "She says calmly") in every lesson here (L1001-1010). The block-wide fix only changed say / subtitles. I kept it because the teacherScript is not read by TTS and the brief limits the fix to say / subtitleEn / subtitleJa. If you want full consistency, apply the same "I say / I" swap to teacherScripts across W33-34 as a central pass.
- **Stress beats written as "FOR, ty" / "THIR, ty"**: probably also in the other number lessons (L991-995 Flight / Seat / Gate reviews, L1015, L1020). Grep say for `\b[A-Z]{3,5}, [a-z]{1,4}\b` and use the hyphen form (FOR-ty, THIR-ty, fif-TEEN).
- **Restaurant name**: if any later lesson (L1011-1020) still says "Little Anchor" or gives evening-only hours for the river restaurant, align it with "River Fish Restaurant".
- **"repair man"**: a grep of world-34.json finds it only in L1007-1008, and these patches cover all of it. "Little Anchor" is only in L1004 (patched).
- **Bare "ize" / "vis" in say** (L1006-1010 "add ize", "Ize again", "Vis means see"): kept. Letter rules read "ize" as /aɪz/, which is the target sound. "vis" may come out /vɪs/, a single C flag. Spelling them out (i, z, e) would lose the sound.
